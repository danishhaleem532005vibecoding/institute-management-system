# 🎓 EduTech IMS — Institute Management System

**EduTech IMS** is a modern web-based **Institute Management System** designed to help educational institutes manage their daily academic and administrative activities through a centralized digital platform.

## 🚀 Features

* 📊 Dashboard and analytics
* 👨‍🎓 Student management
* 👨‍🏫 Teacher/instructor management
* 📚 Course and class management
* 🔐 Authentication system
* 🗄️ Client-side database functionality
* 📈 Reports and data visualization
* 🌱 Seed/demo data support
* 📱 Responsive and modern interface
* ⚡ Fast JavaScript-based application

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Chart.js**
* **Google Fonts**
* Modular JavaScript architecture

The project loads separate modules including `db.js`, `auth.js`, `seed.js`, `modules.js`, and `app.js`, with Chart.js used for reports and analytics.

## 💻 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Open the Project

Navigate to the project folder:

```bash
cd EduTech-IMS
```

### 3. Run the Application

Open `index.html` in your web browser.

For the best development experience, use **VS Code with Live Server** or another local development server.

## 📊 Dashboard & Analytics

EduTech IMS integrates **Chart.js** to support reports and analytics, making it possible to visualize institute-related data in an easy-to-understand format.

## 🔐 Authentication

The application includes a dedicated authentication module through `auth.js`, allowing authentication functionality to remain separate from the main application logic.

## 🎯 Purpose

EduTech IMS aims to reduce manual administrative work and provide institutes with a simple digital solution for organizing students, teachers, classes, courses, reports, and other educational operations.
